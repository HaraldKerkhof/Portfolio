# Portfolio website Harald Kerkhof

Gewone HTML, CSS en JavaScript, zonder framework.

## Openen
1. Open VS Code > File > Open Folder... > kies `Portfolio website/website`.
2. Installeer de extensie **Live Server** (Ritwick Dey).
3. Rechtsklik op `index.html` > **Open with Live Server**. De site opent in je browser en ververst bij elke opslag.

## Structuur
- `index.html`, `about.html`, `contact.html`, `portfolio.html`, `aldharvisio.html`
- `project-detail-art.html?echo=001` toont één Echo-werk (lijst in `js/echo.js`)
- `project-detail-digital-work.html` is een sjabloon: kopieer per project
- `css/style.css` kleuren + typografie uit de styleguide (bovenaan in `:root`)
- `js/main.js` gedeelde header en footer voor alle pagina's
- `assets/` kopieën van de beelden; de originelen blijven in `02-website-assets` en `03-artwork`

## Nog te doen
- Gunter-fontbestand in `assets/fonts/` zetten als `gunter.woff2` of `gunter.otf`
- Beelden voor digital work toevoegen
- Contactformulier koppelen aan een dienst (bv. Formspree)
